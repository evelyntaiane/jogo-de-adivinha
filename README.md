# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I, do IFPB - Campus Campina Grande.

## Integrante
- Preencha aqui seu nome.

## Como jogar
Digite uma letra por vez e clique em **Tentar**. Também é possível pressionar Enter.
O objetivo é descobrir a palavra antes que as seis tentativas acabem.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória entre 12 palavras.
- Palavra escondida por traços.
- Categorias e dicas.
- Controle de tentativas.
- Lista de letras utilizadas.
- Bloqueio de letras repetidas.
- Mensagens de vitória e derrota.
- Botão para iniciar uma nova partida.
- Tentativa de letra usando a tecla Enter.
- Layout responsivo.
